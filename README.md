# Güzellik Merkezi Randevu Sistemi

JavaFX kullanılarak geliştirilmiş masaüstü güzellik merkezi randevu sistemi uygulaması.

## Kullanıcı Tarafı Özellikler
- Kullanıcı kayıt ve giriş sistemi
- Misafir olarak devam edebilme
- Şifremi unuttum işlemleri
- Hizmetleri görüntüleme
- Hizmet detaylarını ve görsellerini inceleyebilme
- Online randevu oluşturabilme
- Tarih, saat ve uzman seçebilme
- Kullanıcı randevu iptal işlemleri
- Profil görüntüleme ve düzenleme
- Son aktiviteleri görüntüleme
- Kampanya ve fırsatları görüntüleyebilme
- İletişim ve mesaj gönderme sistemi

## Admin Tarafı Özellikler
- Yetkilendirilmiş admin hesabı ile giriş yapabilme
- Admin kontrol paneline erişim
- Hizmet ekleme, güncelleme ve silme işlemleri
- Randevu yönetim sistemi
- Kullanıcı mesajlarını görüntüleme
- Kullanıcı randevularını onaylama veya iptal etme
- Hizmet fiyatlandırma yönetimi
- Sistemdeki verileri yönetebilme
- Kullanıcı ve hizmet bilgilerini listeleme

## Kullanılan Teknolojiler
- Java
- JavaFX
- Scene Builder
- MySQL

## Gereksinimler
- JDK 22
- JavaFX SDK 21.0.11
